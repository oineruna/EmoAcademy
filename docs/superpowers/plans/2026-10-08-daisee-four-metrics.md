# DAiSEE 4指標の実装計画

**目的:** 既存EmoAcademyのUIを継承し、学生の4指標と担当教師の平均・推移を統合する。
**構成:** 16フレームFastAPI推論、既存Next.js感情モニター、Supabase RLSと集計RPC。

- [x] APIと型: `[1,16,3,224,224]`入力、`[1,4,4]`出力、最低12枚の顔を要求。モデル・画像・枚数の異常を拒否。
- [x] 学生画面: 250ms間隔の16枚取得、5回平均、終了時キャンセル、保存再試行。既存レイアウトを使用。
- [x] 教師画面: 担当グループ、4指標の平均、5分推移、最新セッション平均、30秒更新。空データには架空値を出さない。
- [x] DB反映: 新テーブルとRLS、担当グループ内に限定した集計RPCを適用し、権限と集計を検証。既存グループRLSの循環も解消。
- [x] 起動: バッチからPython依存準備・API・サイトを起動し、HTTPで動作確認。停止バッチは自身で起動したプロセスだけを対象にする。
- [x] 検証: APIの7テスト、lint、build、サンプル顔画像16枚で実モデル推論、Supabaseの許可・拒否・集計テスト。

GitHubにはこの実装をmainへpushする。既存のGit連携によりVercelのサイトは自動更新される。
公開DAiSEE APIのURL設定は別途必要。ローカル起動では127.0.0.1:7860のAPIを利用する。
ユーザーは実装・Supabase反映・GitHub pushを承認済み。ブラウザ操作は実施していないため、実画面の目視確認は未実施。
